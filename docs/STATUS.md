# Project Status

*Reader: anyone who wants to know how far Syneroym is built.*

Syneroym is pre-alpha and under active development.

- APIs are unstable.
- Features may be incomplete.
- Architecture may change without notice.

**Done:** every milestone in the roadmap's Done table, M0 to M06D. One slice of M5C (cross-app `Bind`) is parked in the backlog. **Deferred on purpose:** the rest of M5, M7, and the later-phase additions; the roadmap's Deferred table gives the reasons. The last milestone done, M06D (reachability and deferred delivery: registry-listed relays, the operator passport and the service mailbox), finished on 2026-10-24.

**Next:** Milestone 8, the Roym value exchange, starting with M08A (open foundation). M7 (resilience and operability) is deferred until after M8 to M10.

The build order, the status of every milestone and a link to each milestone's folder are in [planning/roadmap.md](planning/roadmap.md). What is built today is described in the [requirements](system-requirements-spec.md) and the [architecture](system-architecture.md).
